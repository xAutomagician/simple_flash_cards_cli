# Flashcards CLI


## Запуск

```bash
python cli.py --help
```

Доступные команды:

```text
add
list
train
delete
```

## Добавить карточку

```bash
python cli.py add "Что такое API?" "Интерфейс взаимодействия программ"
```

## Посмотреть карточки

```bash
python cli.py list
```

Пример:

```text
a1b2c3 | Что такое API? | повторить: 2026-08-24
```

## Начать тренировку

```bash
python cli.py train
```

Пример:

```text
Что такое API?
Нажмите Enter, чтобы увидеть ответ

Интерфейс взаимодействия программ

Удалось вспомнить? 1 — да, 2 — нет
> 1
```

Если ответ удалось вспомнить, интервал до следующего повторения увеличится. Если нет — сбросится до одного дня.

## Удалить карточку

Сначала получите ID карточки:

```bash
python cli.py list
```

Затем удалите её:

```bash
python cli.py delete a1b2c3
```

Данные хранятся локально в файле `cards.csv`.
